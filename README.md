# BaseBoard
A Family Calendar for board.fun

## How To Install
1. Download the baseboard.webapp.zip

2. Every Board serves the web UI at http://<device>:8843/. From a browser on the same network you can:

On Board, open Settings > System > Pair a computer > Show pairing code. Board’s web address will be listed.
Browse to http://<that-address>:8843/ then enter the six-digit code in the browser.
That pairs your browser and unlocks the interface.

3. Click "Install app" and upload the baseboard.webapp.zip file.
